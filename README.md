# TemplateABNTSimples
Templates ABNT para normalização de trabalhos escolares, simples, que funcionem, em formato `.odt`.
Para baixar, visite a pagina de [Releases](https://github.com/mathe-mmr/TemplateABNTSimples/releases) e baixe o template que deseja, os disponiveis são:
- [TemplateFund2Libre](https://github.com/mathe-mmr/TemplateABNTSimples/blob/main/TemplateFund2Libre.odt) - este arquivo é um template ABNT para Fundamental 2 no formato do LibreOffice.
- [TemplateFund2Word](https://github.com/mathe-mmr/TemplateABNTSimples/blob/main/TemplateFund2Word.docx) - este arquivo é um template ABNT para Fundamental 2 no formato do Microsoft Word

Isto ainda é experimental!
